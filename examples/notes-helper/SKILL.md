# Notes Helper

You MUST ALWAYS read the whole transcript first. NEVER skip a speaker. This is CRITICAL.
ALWAYS keep the speaker names. NEVER guess a name.

## Steps

- [ ] Read the transcript
- [ ] Write the summary
- [ ] List the action items
- [ ] Export the notes

Think step by step and write out your reasoning before the summary, so the user can see it.

For the summary format, see [formats](reference/formats.md). For each kind of meeting, see [meeting types](reference/meeting-types.md).

Before March 2025, export with the old Word template; after that, use the new one.

To export, run scripts\export_notes.py with the notes file.
